# أكاديمية سُرُج

صفحة الإطلاق المؤقتة للموقع الإلكتروني لأكاديمية سُرُج.

الموقع: https://sorog.net/

صفحة HTML وCSS متجاوبة، تستعمل الشعار الأصلي المرفق دون إعادة رسمه. خط Tajawal من Google Fonts، مع بدائل محلية. لا تحتاج إلى تثبيت حزم أو عملية بناء.

## النشر

GitHub Pages من فرع `main` والمجلد الجذري `/`. يحدد ملف `CNAME` الدومين `sorog.net`.

## تشغيل محلي

يمكن فتح `index.html` مباشرة، أو تقديم المجلد من خادم ملفات ثابتة.
